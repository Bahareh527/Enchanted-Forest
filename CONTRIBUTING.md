# Contributing

Thank you for your interest in Enchanted Forest.

1. Open an issue describing the change or bug.
2. Keep the game dependency-free and compatible with Java 17.
3. Add or update a test in `src/test/java` for behavior changes.
4. Run `scripts/verify.sh` or `scripts/verify.ps1` before submitting a pull request.
5. Keep commits focused and write a concise explanation of the user-visible effect.

By contributing, you confirm that you have the right to submit your work. No open-source license is currently granted for the repository; discuss licensing with the maintainers before substantial reuse.
